
# Практична робота №3. Компонентний підхід та основи React

## Мета роботи
Опанувати основи бібліотеки **React** та її ключові концепції (**компоненти**, **стан**, **властивості**). Здобути практичні навички рефакторингу існуючого JavaScript-застосунку (гра **Minesweeper**), розробленого у попередніх лабораторних роботах, з використанням **компонентного підходу**. Навчитися застосовувати сучасні підходи до стилізації (**CSS Modules**).

## Завдання
Необхідно реалізувати (переписати) раніше розроблену гру Minesweeper (HTML, CSS, JS) на фреймворку **React**, дотримуючись **компонентної архітектури**.

1. В `src/pages` додати персональну директорію у форматі: `{ПрізвищеІм'я}`.
2. В `src/App.jsx` додати `Route` на сторінку вашої гри, що використовуватиме шлях (path) `{прізвище-ім'я}`.
3. В `src/pages/Game/index.jsx` додати свою імплементацію гри в список (`implementations`).
4. У створеній директорії (`src/pages/{ПрізвищеІм'я}`) створити основний компонент гри.
5. Переписати Minesweeper, використовуючи компонентний підхід. Необхідно розбити інтерфейс та логіку на менші, логічно відокремлені компоненти (наприклад: `Board`, `Cell`, `Timer`, `GameStatus`, `RestartButton`).
6. Для стилізації компонентів гри використати **модульні стилі (CSS Modules)**.

## Система оцінювання
* **Налаштування проєкту:** 1 бал (роутинг, особиста директорія).
* **Компонентна структура:** 2 бали (логічне розбиття інтерфейсу на окремі компоненти та їх взаємодія).
* **Керування станом (State Management):** 2 бали (правильна міграція логіки гри, робота зі станом та передача props).
* **Стилізація:** 1 бал (використання CSS Modules).
* **Якість коду:** 2 бали (чистота коду, відсутність дублювання, дотримання принципів читабельності та стандартів React).
* **Якісне проведення рецензування (Code Review):** 2 бали (глибина аналізу коду іншого студента, корисні зауваження та пропозиції).

**Максимальна кількість балів: 10.**

> **Примітка:** Робота оцінюється лише за умови наявності звіту.

> **Важливо:** Для цієї лабораторної роботи необхідно використовувати репозиторій з приставкою **`-react-`** у назві. Приклад: `cs13-minesweeper-react-2026`. Це уникає конфліктів з раніше створеним репозиторієм без React та ясно позначає версію проєкту.
## Умови здачі
1. Реалізувати рішення у своїй директорії (`src/pages/{ПрізвищеІм'я}`), оновити файл роутингу (напр., `src/App.jsx`) та додати імплементацію на сторінку Play Game (`src/pages/Game/index.jsx`).
2. Створити окрему гілку з назвою у форматі: `lab3/[Прізвище] [Ім'я]-[короткий опис, напр. react-migration]`.
3. Завантажити зміни до репозиторію (commit + push) та відкрити Pull Request.
4. Пройти код-рев'ю від **викладача (обовʼязково)** та іншого студента (опціонально).
5. Провести рецензування коду іншого учасника курсу (опціонально).
6. Підготувати звіт у форматі PDF та завантажити його на платформу Moodle. Наявність звіту є обов'язковою. Шаблон звіту можна знайти в секції **"Додаткові матеріали"**.
